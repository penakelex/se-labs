# Лабораторная работа №1

Графический интерфейс с динамической разметкой.

Аниматор сортировки. Текстовые поля с числами, графическое отображение процесса перестановки
элементов в массиве. Подсветка текущего и минимального элементов, перенос элементов «вверх-влево
(вправо)-вниз». Быстрая сортировка с плавной анимацией.

## Что реализовано

- [x] Экран меню: ручной ввод массива, генерация случайного массива с настраиваемым диапазоном.
- [x] Экран анимации: массив `SortElement`, автоматическое масштабирование под размер окна.
- [x] Подсветка элементов и состояний (`SortElement` — диапазон, опорный элемент, фиксация).
- [x] Алгоритм быстрой сортировки с планированием шагов (`QuickSorter`).
- [x] Плавная анимация перестановок с подъемом, перемещением и опусканием (`SortAnimator`).
- [x] Юнит-тесты и UI-тесты (`JUnit 5`, `AssertJ`, `JavaFxTestBase`).

## Запуск приложения

```bash
./gradlew :lab1:run

```

## Тестирование

Проект включает в себя модульные тесты для модели данных и UI-тесты элементов интерфейса:

```bash
# Запуск тестов для лабораторной работы №1
./gradlew :lab1:test

# Запуск всех проверок (тесты + Checkstyle + PMD + SpotBugs)
./gradlew :lab1:check

```

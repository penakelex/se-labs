# Лабораторная работа №3

Разработка элемента GUI с динамическим поведением.
Движок уровня и индикатор значения в логарифмической шкале (децибел, dB).

## Задание

Разработать производный класс на основе базового элемента графического интерфейса с динамическим
поведением, способный накапливать, отображать и возвращать накопленные данные. При необходимости
периодической передачи данных с определенной частотой элемент получает при конструировании интерфейс
слушателя события (с методом «очередное значение данных»).

**Специфика варианта:**

- Задается целочисленное значение `V0` (нулевой уровень).
- При получении значения `V` индикатор вычисляет уровень в дБ по формуле: `20 * log10(V / V0)`.
- Диапазон шкалы задается (например, +/- 100 дБ).
- При перемещении движка через CallBack возвращается значение позиции в исходном целом виде
  (обратное преобразование).
- Визуализация: вертикальный движок уровня и шкала-индикатор с подписями (например, 15, 0, -21,
  -39, -∞).

## Что реализовано

- [x] **Базовый элемент GUI с динамическим поведением**: `LogarithmicLevelPane` (наследуется от
  `VBox`, адаптация под JavaFX вместо Swing `JPanel`).
- [x] **Логарифмическая шкала (`LogScaleModel`)**: прямое (`calculateDecibels`) и обратное
  (`calculateValueFromDecibels`) преобразование по формуле `20*log10(V/V0)`, ограничение диапазона.
- [x] **Движок и индикатор**: `LogarithmicLevelPane` содержит вертикальный слайдер и цветовой метр
  (`MeterRenderer`), отображающий текущий уровень.
- [x] **CallBack при перемещении движка**: при изменении положения слайдера вычисляется исходное
  целое значение `V` и передается через слушатель.
- [x] **Интерфейс слушателя**: `NextDataListener` с методом `onNextData(int value)` для
  периодической передачи данных.
- [x] **Накопление данных**: `DataAccumulator` хранит историю значений с ограничением размера,
  сквозной нумерацией и потокобезопасным доступом.
- [x] **Периодическая передача данных**: `DataPublisher` (на базе JavaFX `Timeline`) вызывает
  слушателя с заданной частотой (периодом).
- [x] **Отображение истории**: `HistoryManager` выводит накопленные данные в `ListView` с
  автопрокруткой.
- [x] **Настройки**: панель `SettingsController` с валидацией ввода `V0`, минимального/максимального
  дБ, периода обновления и лимита истории.
- [x] **Юнит-тесты**: `DataAccumulatorTest`, `LogScaleModelTest` (проверка формул, границ и
  накопления).

## Ключевые классы и соответствие заданию

- **`LogScaleModel`**: реализует математическую часть задания. Содержит `V0`, границы диапазона в дБ
  и методы `calculateDecibels(int value)` (прямая формула) и `calculateValueFromDecibels(double db)`
  (обратная формула для CallBack).
- **`LogarithmicLevelPane`**: производный класс GUI (наследник `VBox`). Накапливает и отображает
  данные. В конструкторе принимает `NextDataListener`, которому передает новые значения.
- **`NextDataListener`**: интерфейс слушателя с методом `onNextData(int value)`, как того требует
  задание.
- **`DataPublisher`**: внутренний таймер, который с заданной периодичностью генерирует события
  «очередное значение данных» и передает их слушателю.
- **`DataAccumulator`**: потокобезопасное хранилище накопленных данных.
- **`MeterRenderer`**: отрисовка вертикальной шкалы-индикатора (цветовой метр) и подписей (0, -36,
  -72 и т.д.).

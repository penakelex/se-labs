# Лабораторная работа № 4

Модель физического объекта с подпиской на события (шаблон «Наблюдатель») на примере обработки
звукового сигнала в формате WAV.

## Вариант задания

> Физический объект – звуковая волна в формате wave-файла. Ручное проматывание и автоматическое
> проигрывание. Объекты – адаптеры для изменения амплитуды и задержки сигнала, микширования –
> суммирования сигналов от разных источников (паттерн прокси).

## Что реализовано

- Загрузка WAV-файла из ресурсов (`WaveSource.fromResource`) либо генерация тестового тона
  (`WaveSource.generateTone`), если файла нет.
- Поканальная настройка **амплитуды** (0.0 – 1.0) и **задержки** (0 – 2 с) — реализовано как
  адаптер `SignalProcessor` над исходным `SignalSource` (паттерн «Прокси/Адаптер»).
- **Микширование** нескольких источников в один сигнал — `SourceMix` (паттерн «Композиция»):
  сумма каналов с учётом их задержек, с ограничением результата в диапазоне `[-1.0, 1.0]`.
- Управление воспроизведением через `PlaybackController` (обёртка над `javax.sound.sampled.Clip`):
  play / pause / stop / seek, периодическое обновление состояния во `WaveformView` через
  `AnimationTimer`.
- UI на FXML + CSS: панель с осциллограммой (`WaveformView` на `Canvas`), кнопки play/pause/stop,
  слайдер перемотки, слайдеры амплитуды и задержки для каждого источника.
- Изменение амплитуды/задержки пересобирает `Clip` с дебаунсом 100 мс (`PauseTransition`) и
  продолжает воспроизведение с текущей позиции.

## Структура пакетов

```
org.nstu.se.lab4
├─ Launcher.java              # точка входа (не наследует Application)
├─ SoundApplication.java      # JavaFX Application
├─ Messages.java              # загрузка app.properties
├─ ResourcePaths.java         # пути к FXML и CSS
├─ audio/
│  ├─ SignalSource.java       # интерфейс источника сигнала
│  ├─ WaveSource.java         # WAV-файл или сгенерированный тон
│  ├─ SignalProcessor.java    # прокси: амплитуда + задержка над SignalSource
│  ├─ SourceMix.java          # композиция нескольких каналов
│  ├─ MixSettings.java        # настройки каналов (immutable record)
│  ├─ PlaybackController.java # управление Clip, кодирование в PCM
│  └─ event/
│     ├─ PlaybackListener.java
│     └─ PlaybackState.java
└─ ui/
├─ MainController.java     # главный контроллер, AnimationTimer
├─ SourceRowController.java# контроллер строки с настройками канала
└─ WaveformView.java       # Canvas-осциллограмма + playhead
```

## Применённые паттерны

| Паттерн              | Где                                                                                                             |
|----------------------|-----------------------------------------------------------------------------------------------------------------|
| **Адаптер / Прокси** | `SignalProcessor` — прокси над `SignalSource`, добавляет амплитуду и задержку                                   |
| **Композиция**       | `SourceMix` — сумма нескольких `SignalSource` с учётом задержек                                                 |
| **Наблюдатель**      | `PlaybackController` + `AnimationTimer` → `WaveformView` и контроллеры FXML                                     |
| **MVC**              | FXML (View), `MainController`/`SourceRowController` (Controller), `PlaybackController` + `SignalSource` (Model) |
| **Immutable**        | `MixSettings`, `SourceMix.Channel`, `PlaybackController.State`, `PlaybackState`                                 |

## Запуск

```bash
./gradlew :lab4:run
```

Для работы звука нужен аудиовыход; при отсутствии WAV-файлов в ресурсах источники генерируются
программно (синусоида 440 Гц и 660 Гц, 5 секунд, 44.1 кГц).

## Управление

- **▶ / ⏸** — play / pause;
- **⏹** — стоп с возвратом в начало;
- **слайдер перемотки** — seek по позиции (в секундах);
- **Амплитуда** — 0.0 … 1.0 для каждого канала;
- **Задержка** — 0 … 2 с для каждого канала;
- **Esc** — снять фокус с кнопки (чтобы пробел не «нажимал» play).

## Тесты

Тестами покрыты чистые (без JavaFX) классы пакета `audio`:

- `WaveSourceTest` — генерация тона (частота, сэмпл-рейт, форма, ограничения индексов) и
  обработка отсутствующего ресурса.
- `SignalProcessorTest` — амплитуда, задержка, границы индексов, валидация параметров.
- `SourceMixTest` — пустой микс, одиночный канал, задержка, клиппинг в `[-1.0, 1.0]`, сэмпл-рейт
  первого канала.
- `MixSettingsTest` — значения по умолчанию, неизменяемость (immutability), валидация амплитуды
  и задержки.

Вспомогательный `FixedSignalSource` — детерминированный источник для тестов.

Запуск только тестов лабы:

```bash
./gradlew :lab4:test
```

Запуск всех проверок (тесты + Checkstyle + PMD + SpotBugs + Spotless):

```bash
./gradlew :lab4:check
```
